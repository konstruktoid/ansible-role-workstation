# Security Policy

## Supported Versions

The current [upstream](https://github.com/konstruktoid/ansible-role-workstation)
and the [latest published version](https://github.com/konstruktoid/ansible-role-workstation/releases) are supported.

## Reporting a Bug or Vulnerability

Report a bug, a vulnerability, or any other unexpected behavior by submitting an issue, or contribute a
correction by creating a pull request.
