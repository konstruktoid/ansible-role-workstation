# Security Policy

## Supported Versions

The current [upstream](https://github.com/konstruktoid/ansible-role-workstation)
and the [latest published version](https://github.com/konstruktoid/ansible-role-workstation/releases) are supported.

## Reporting a Bug

Report a bug, or any other unexpected behavior that does not have security impact, by submitting an
issue, or contribute a correction by creating a pull request.

## Reporting a Vulnerability

Do not report vulnerabilities through public issues or pull requests, since that discloses them before
a fix is available. Use
[private vulnerability reporting](https://github.com/konstruktoid/ansible-role-workstation/security/advisories/new)
instead, which is enabled on this repository. If you are unsure whether an issue has security impact,
report it privately and it will be redirected if it does not.
